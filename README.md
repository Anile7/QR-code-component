# QR Code Component 🌸

A modern, responsive QR code card built with *HTML* and *CSS*.  
This component focuses on simplicity, visual balance, and clean typography &mdash; perfect for practicing layout and alignment.

---

## About 📝 

This project is a small front-end component challenge.
It demonstrates how to center content using Flexbox, apply consistent spacing, and design a neat, minimal user interface.
